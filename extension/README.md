# Cortex for your browser

Ask Cortex about the page you are reading, or the text you selected, from Chrome, Edge, Brave or
any Chromium browser. Cortex answers from your computer through its local API; the extension talks
only to `127.0.0.1`.

1. In Cortex: Settings → General → Local API → turn it on, and copy the API key.
2. In the browser: open `chrome://extensions`, turn on Developer mode, choose **Load unpacked**,
   and pick this `extension` folder.
3. Click the Cortex icon, paste the key, and ask. Right-click selected text for
   **Ask Cortex about the selection**. **Continue in Cortex** opens the question, with the page
   attached, in a new chat in the app.
