# Lumo for your browser

Ask Lumo about the page you are reading, or the text you selected, from Chrome, Edge, Brave or
any Chromium browser. Lumo answers from your computer through its local API; the extension talks
only to `127.0.0.1`.

1. In Lumo: Settings → General → Local API → turn it on, and copy the API key.
2. In the browser: open `chrome://extensions`, turn on Developer mode, choose **Load unpacked**,
   and pick this `extension` folder.
3. Click the Lumo icon, paste the key, and ask. Right-click selected text for
   **Ask Lumo about the selection**. **Continue in Lumo** opens the question, with the page
   attached, in a new chat in the app.
